# 商城 MVP 演示流程（非技术人员版）

本文说明在浏览器里如何完成一次「能讲清楚」的演示：谁在哪个页面点什么、会看到什么。默认前端开发地址为 `http://localhost:5173`（以实际部署为准），左侧深蓝菜单为「用户端 / 商家端 / 管理端」入口。

**演示前请确认**

- 已启动后端（默认 `http://localhost:8080`）与前端，且前端能正常打开商品列表。
- 准备好**三个不同身份**的演示账号（均为「用户 ID + 统一口令」登录，无单独注册页）：
  - **管理员**：用户 ID 必须在后端配置的 `mall.auth.admin-user-ids` 中（默认常见为 **1**）。
  - **普通买家**：例如种子数据中的 **1001**（或任意非管理员、非商家主账号的 ID，视库中数据而定）。
  - **商家主账号**：用于入驻与店铺后台；若走「新商家入驻」演示，请使用**库中尚未申请过商家**的用户 ID；若使用种子数据，常见为 **2001**（已是已通过商家，可跳过入驻与审核步骤）。
- 当前演示环境默认采用自营单店模式，`mall.feature.multi-shop` / `split-order` / `settlement` 均为 false，多商户子单能力仅做结构预留，未接入本期交易主流程。

**登录口令**

- 与后端配置一致，默认多为 **`mvp-demo`**（可被环境变量 `MALL_AUTH_LOGIN_PASSWORD` 覆盖）。登录页默认已预填口令，主要改「用户 ID」即可。

---

## 演示路径说明（二选一）

**路径 A：完整故事（新商家从入驻到卖货）**  
按下面步骤 **1 → 12** 顺序做：先新商家申请 → 管理员通过 → 商家上架 → 买家下单 → 商家发货 → 买家确认收货 → 管理员抽查。

**路径 B：省时间（库里已有已通过商家与上架商品）**  
可从步骤 **1** 进入后，直接从 **步骤 7**（买家登录）开始，用已有上架商品演示下单与后续；**步骤 3～6** 可口头说明「已提前完成」。

---

## 步骤 1：打开商城，确认能逛商品

| 角色 | 操作说明 |
|------|----------|
| **所有人** | 在浏览器地址栏打开前端首页（如 `http://localhost:5173`），一般会进入 **商品列表**。 |
| **访问页面** | 左侧点 **「用户端 → 商品列表」**，或直接看首页是否已是商品列表。 |
| **点击操作** | 可在搜索框输入关键字，点 **「搜索」**；可点 **「上一页 / 下一页」** 翻页。 |
| **预期结果** | 表格中出现商品名称、价格、库存、店铺名；右上角显示 **「未登录」** 属正常。 |

本步**不要求登录**。

---

## 步骤 2：管理员登录（为后面审核做准备）

| 角色 | 操作说明 |
|------|----------|
| **管理员** | 演示「平台管理人员」。 |
| **访问页面** | 右上角点 **「登录」**，进入 **登录** 页。 |
| **点击操作** | 「用户 ID」填 **1**（或您环境配置的管理员 ID）；「口令」填 **`mvp-demo`**（或与运维确认后的口令）；点 **「登录」**。 |
| **预期结果** | 回到商品列表或之前页面；右上角显示 **「userId=1 / role=ADMIN」**（数字以实际为准）；左上角菜单中的 **管理端** 菜单可正常进入。 |

若用两个浏览器分别扮演管理员与买家，可避免来回退出登录。

---

## 步骤 3：商家提交入驻申请

| 角色 | 操作说明 |
|------|----------|
| **商家** | 使用**尚未申请过商家**的用户 ID（若与上一步同一浏览器，需先右上角 **「退出」**，再登录该商家用户 ID）。 |
| **访问页面** | 登录后，左侧点 **「商家端 → 商家入驻」**。 |
| **点击操作** | 填写 **商家名称、联系人、联系电话**；**资质文本**可随便写几句说明；点 **「提交申请」**。 |
| **预期结果** | 页面下方出现绿色提示类文字，包含 **商家 ID** 与状态 **PENDING（待审核）**；请记下 **商家 ID**，管理员审核要用。 |

**买家 / 管理员**本步无需操作。

---

## 步骤 4：管理员审核通过商家

| 角色 | 操作说明 |
|------|----------|
| **管理员** | 使用步骤 2 的管理员账号（若当前不是管理员，请退出后重新用管理员登录）。 |
| **访问页面** | 左侧点 **「管理端 → 商家审核」**。 |
| **点击操作** | 筛选可选 **「待审核」**；在表格中找到刚申请的商家，点 **「通过」**。若演示驳回，可点 **「驳回」** 并在弹出框输入原因（需填写）。 |
| **预期结果** | 列表刷新后，该商家 **状态** 变为 **APPROVED（已通过）**；备注列会更新。 |

**买家**本步无需操作。**商家**可刷新或稍后登录 **「商品管理」** 验证是否可操作（见下一步）。

---

## 步骤 5：商家新建商品

| 角色 | 操作说明 |
|------|----------|
| **商家** | 使用**已通过审核**的商家用户 ID 登录。 |
| **访问页面** | 左侧 **「商家端 → 商品管理」**；点右上角 **「新增商品」**（进入 **新增商品** 页）。 |
| **点击操作** | 填写 **商品名称**（必填）、**价格、库存**（必填）；副标题、主图 URL、详情可填可不填；点 **「新增商品」**。 |
| **预期结果** | 弹出 **「新增成功」**；自动回到 **商品管理** 列表，能看到新商品，**状态** 一般为 **OFF_SHELF（未上架）**。 |

**买家 / 管理员**本步无需操作。

---

## 步骤 6：商家上架商品

| 角色 | 操作说明 |
|------|----------|
| **商家** | 仍在 **商品管理** 列表。 |
| **访问页面** | **「商家端 → 商品管理」**。 |
| **点击操作** | 在刚新增的商品那一行，点 **「上架」** 链接（若已是上架状态，则显示为「下架」，不要点错）。 |
| **预期结果** | 列表刷新后，该商品 **状态** 变为 **ON_SHELF（已上架）**。此时普通用户在 **商品列表** 里应能搜到该商品（可让买家新开窗口验证）。 |

**买家 / 管理员**本步无需操作。

---

## 步骤 7：买家登录并选购

| 角色 | 操作说明 |
|------|----------|
| **买家** | 使用普通用户 ID（如 **1001**）登录（若与商家同浏览器，先 **「退出」** 再登录）。 |
| **访问页面** | **「用户端 → 商品列表」**；在表格中某商品行点 **「查看详情」** 进入 **商品详情**。 |
| **点击操作** | 在数量框输入购买数量（默认 1）；点 **「加入购物车」**。 |
| **预期结果** | 若未登录会先跳到登录页，登录成功后会回到详情；加入成功会弹出浏览器提示 **「已加入购物车」**。 |

**商家 / 管理员**本步无需操作。

---

## 步骤 8：买家查看购物车

| 角色 | 操作说明 |
|------|----------|
| **买家** | 保持买家已登录。 |
| **访问页面** | 左侧 **「用户端 → 购物车」**。 |
| **点击操作** | 无需额外按钮，进入即加载列表。 |
| **预期结果** | 表格中显示刚加入的商品、店铺、单价、数量及合计金额。 |

说明：当前 MVP 购物车页**没有**「勾选 / 取消勾选」开关；下单时系统会按后端约定使用已勾选为真的购物车行（演示前请保证测试数据购物车行为符合预期，或沿用种子数据演示）。

---

## 步骤 9：买家提交订单并模拟支付

| 角色 | 操作说明 |
|------|----------|
| **买家** | 保持买家已登录。 |
| **访问页面** | 左侧 **「用户端 → 提交订单」**。 |
| **点击操作** | 先点 **「创建订单」**；看到下方蓝色区域出现订单号与状态后，再点 **「模拟支付最新订单」**。 |
| **预期结果** | 第一次点击后提示 **待支付** 及订单号；第二次点击后提示 **支付成功**，状态一般为 **PAID（已支付）**。 |

**商家 / 管理员**本步无需操作。

---

## 步骤 10：商家发货

| 角色 | 操作说明 |
|------|----------|
| **商家** | 退出买家，重新用**商家主账号**登录。 |
| **访问页面** | 左侧 **「商家端 → 店铺订单」**。 |
| **点击操作** | 在状态为 **PAID** 的订单行，点 **「发货」**；在第一个弹窗输入 **快递单号**（必填）；第二个弹窗可输入发货备注或留空；确定。 |
| **预期结果** | 提示 **「发货成功」**；该行 **状态** 变为 **SHIPPED（已发货）**，并显示快递单号与发货时间。可点 **「详情」** 查看本店商品明细与收货信息。 |

**买家 / 管理员**本步无需操作。

---

## 步骤 11：买家确认收货

| 角色 | 操作说明 |
|------|----------|
| **买家** | 重新用买家账号登录。 |
| **访问页面** | 左侧 **「用户端 → 我的订单」**。 |
| **点击操作** | 找到状态为 **SHIPPED** 的订单，点 **「确认收货」**；在浏览器确认框中选确定。 |
| **预期结果** | 提示 **「确认收货成功」**；订单状态变为 **COMPLETED（已完成）**，并显示完成时间（若有）。 |

**商家 / 管理员**本步无需操作。

---

## 步骤 12：管理员查看全平台订单与商品（演示监管）

| 角色 | 操作说明 |
|------|----------|
| **管理员** | 使用管理员账号登录。 |
| **访问页面** | 左侧 **「管理端 → 订单列表」** 或 **「管理端 → 商品列表」**。 |
| **点击操作** | 在 **订单列表**：可按状态下拉、输入订单号片段，点 **「查询」**。在 **商品列表**：可输入商品关键字、选择上下架状态，点 **「查询」**；对仍在上架的商品可点 **「下架」** 做演示。 |
| **预期结果** | 能看到刚才买家产生的订单及状态变化；商品列表与下架操作与库中数据一致，下架后商品状态变为 **OFF_SHELF**。 |

**买家 / 商家**本步无需操作。

---

## 演示小结（可照着念）

1. **买家**：逛商品 → 加购 → 提交订单页一键下单并模拟付款 → 等商家发货 → 我的订单里确认收货。  
2. **商家**：入驻 → 等管理员通过 → 新增商品并上架 → 在店铺订单里对已付款订单发货。  
3. **管理员**：登录后审商家、查全站订单、必要时下架违规或演示用商品。

---

## 常见问题（给演示辅助人员）

| 现象 | 可能原因与处理 |
|------|----------------|
| 点管理端菜单又回到商品列表 | 当前登录用户 **不是管理员 ID**，请用配置中的管理员用户重新登录。 |
| 商家端提示未通过审核 | 管理员尚未 **通过** 该用户的入驻申请，回到步骤 4。 |
| 商品列表里没有新商品 | 商家未点 **「上架」**，或商品已删除/下架，回到步骤 6 或换商品演示。 |
| 创建订单失败 | 购物车里没有可下单的勾选商品、库存不足、或商品已下架；检查步骤 7～8 与库存。 |
| 没有「发货」按钮 | 订单不是 **已支付** 状态；请先完成步骤 9 的模拟支付。 |
| 登录口令不对 | 与运维确认 `mall.auth.login-password`，与登录页填写一致。 |

更细的接口与数据表说明见：`docs/mvp-api-reference.md`、`docs/mvp-acceptance-checklist.md`。
