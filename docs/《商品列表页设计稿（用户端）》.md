《商品列表页设计稿（用户端）》
一、页面定位

商品列表页是用户端商城的核心入口页，承担以下目标：

展示可售商品
支持用户快速筛选、搜索、浏览
引导用户进入商品详情页
提升用户下单转化效率

这个页面不追求复杂炫技，重点是：清晰、好找、像正常商城、便于后续扩展。

二、页面目标
2.1 用户目标

用户进入页面后，能够快速完成以下动作：

看见当前可买的商品
按分类查看商品
按关键词搜索商品
按价格/销量/最新等方式排序
快速了解商品基本信息
点击进入商品详情页
对感兴趣商品进行收藏/加入购物车（如当前版本支持）
2.2 业务目标

页面需要支撑商城基础转化链路：

商品曝光
商品点击
搜索转化
分类转化
活动商品曝光
为后续推荐、营销、专题页做承接
三、页面整体结构

商品列表页建议采用标准商城布局，自上而下分为：

顶部导航区
搜索区
分类/筛选区
排序工具栏
商品列表区
分页/加载更多区
底部信息区

五、各区域详细设计
5.1 顶部导航区
作用

承载商城一级导航和用户常用入口。

建议内容

左侧：

Logo / 商城名称

中间：

首页
商品列表
购物车
我的订单

右侧：

登录 / 注册
用户头像 / 用户昵称
退出登录
交互说明
当前页高亮“商品”
未登录时显示“登录 / 注册”
已登录时显示用户信息和退出按钮
点击 Logo 返回商城首页或商品列表页
5.2 搜索区
作用

支持用户按关键词查找商品。

组件结构
搜索输入框
搜索按钮
可选：搜索历史 / 热门关键词
搜索内容支持
商品名称
商品简介
分类相关词
品牌词（后续可扩展）
占位文案建议
搜索你想要的商品
请输入商品名称关键词
交互说明
回车触发搜索
点击按钮触发搜索
搜索条件应同步到 URL 参数，便于刷新保留状态
搜索后列表刷新，页码重置为第 1 页
5.3 分类区
作用

帮助用户快速按商品类型浏览。

展示形式

推荐使用横向分类 tab：

全部
手机数码
家用电器
服饰鞋包
食品生鲜
居家日用
更多...
交互说明
点击分类切换商品列表
当前分类高亮
支持和搜索、排序联动
切换分类后自动回到第一页
扩展建议

后续可升级为：

左侧分类导航
二级分类展开
分类图标化展示
5.4 排序工具栏
作用

满足用户不同浏览偏好。

推荐排序项
综合
销量
价格
最新
价格排序逻辑

价格点击一次：升序
再点击一次：降序
再次点击：取消价格排序，回到默认逻辑

可选右侧功能
仅看有货
促销商品
筛选按钮
交互说明
排序切换后立即刷新列表
当前排序项高亮
价格排序需要箭头状态明确
5.5 商品列表区

这是页面主体，建议使用卡片栅格布局。

布局建议

PC 端：

一行 4 个商品卡片
卡片间距统一
整体宽度居中

平板端：

一行 2~3 个

移动端：

一行 2 个，或单列大卡片
六、商品卡片设计

每个商品卡片建议包含以下信息：

6.1 商品图片
主图
固定比例，建议 1:1
图片区域支持懒加载
无图时显示默认占位图
6.2 商品名称
最多显示两行
超出省略
名称需要是用户最容易识别的字段

示例：

Apple iPhone 15 128G 全网通
家用空气炸锅 5L 大容量智能款
6.3 商品卖点
一行简短描述
可展示“轻便 / 爆款 / 新品 / 品牌直发”等信息
没有时可不展示，避免空洞文案
6.4 价格区

建议包含：

当前售价
原价（如有优惠）
折扣标识（可选）

示例：

￥2999
￥3599（删除线）
6.5 销量/评价信息

可选展示：

已售 235 件
98% 好评
月销 1200+

当前版本若无评价体系，可先保留销量字段。

6.6 状态标签

可选标签：

新品
热卖
限时优惠
已售罄
6.7 操作按钮

可选两种模式：

模式 A：简洁型

整张卡片可点击，进入详情页
卡片底部不放按钮

模式 B：电商型

底部放：

查看详情
加入购物车

当前建议优先采用 模式 A 或 “详情 + 加购”简化版，避免卡片过重。

七、商品卡片交互设计
鼠标悬停

PC 端建议增加轻交互：

卡片阴影增强
微弱上浮
图片轻微缩放
点击行为
点击卡片主体：进入商品详情页
点击加入购物车：加入成功 toast 提示
点击商品图片或标题：同样进入详情页
状态处理
商品下架：显示“已下架”，不可购买
库存不足：显示“库存紧张”
售罄：按钮置灰，显示“已售罄”
八、分页/加载更多设计
PC 端建议

使用标准分页器：

上一页
页码
下一页
跳转页
移动端建议

可改为“加载更多”或滚动触底加载

交互要求
切页时保留搜索、分类、排序条件
切页后页面滚动到商品列表顶部
无数据时显示空状态，不要留白
九、空状态设计

当没有匹配商品时，页面展示空状态：

展示内容
空图标 / 插画
文案：暂无符合条件的商品
次级文案：换个关键词试试，或者看看其他分类
按钮：返回全部商品
适用场景
搜索无结果
分类下无商品
筛选条件过严
十、加载态设计
首次进入页面
顶部区域正常显示
商品列表区使用骨架屏
列表切换时
可保留页面骨架
或商品区域局部 loading
原则

不要整页白屏加载。
优先保证页面结构先出来，再加载数据。

十一、异常态设计

接口异常时展示：

错误提示文案：商品加载失败，请稍后重试
重试按钮
保留顶部搜索和分类，方便用户继续操作
十二、视觉风格建议

整体风格建议：简洁、标准商城风、偏实用，不做花哨设计。

视觉关键词
清晰
干净
易读
商城化
轻运营感
色彩建议
主色：品牌主色
价格色：红色系 / 橙红系
标签色：适度区分，不要过多
背景：浅灰底 + 白色卡片
字体层级建议
页面标题：较大
商品名：中等偏重
卖点：次级灰色小字
价格：醒目加粗
辅助信息：小号浅色
十三、响应式设计建议
PC 端
顶部横向导航
分类横向 tab
四列商品卡片
平板端
导航可适当压缩
商品卡片改三列或两列
手机端
顶部保留搜索
分类可横滑
排序栏精简
商品改双列或单列紧凑模式
十四、数据字段建议

商品列表页前端至少需要以下字段：

{
  id: number | string,
  name: string,
  subtitle?: string,
  coverUrl: string,
  price: number,
  originalPrice?: number,
  salesCount?: number,
  stock?: number,
  categoryId?: number | string,
  categoryName?: string,
  status?: 'on_sale' | 'off_shelf' | 'sold_out',
  tags?: string[]
}

十九、最终页面效果预期

用户进入商品列表页后，第一眼就能看到：

顶部商城导航清晰
搜索入口明显
分类与排序容易操作
商品卡片整齐统一
价格信息突出

整体效果应接近“一个正常能卖货的商城页面”，而不是 demo 感很重的拼凑页面。
