《订单管理页设计稿（管理端）》
一、页面定位

订单管理页是后台系统的核心业务页面之一，用于：

查看所有订单
管理订单状态流转
查询订单详情
处理售后/异常订单（后续扩展）

👉 本页面的核心原则：
像企业后台、信息密集但清晰、操作高效、可扩展。

二、页面目标
2.1 管理端目标
快速查看订单整体情况
精准筛选目标订单
高效处理订单（发货 / 完成 / 取消等）
快速进入订单详情页
2.2 业务目标
支撑订单全生命周期管理
提供数据统计基础
为售后、财务、运营提供数据支撑
三、页面整体结构

页面采用标准后台布局：

六、订单状态设计（非常关键）

建议标准化：

状态	说明

待发货	商家待处理
已发货	已发出
已完成	交易完成

点击“取消” → 二次确认
